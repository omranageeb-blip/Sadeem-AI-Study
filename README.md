# SADEEM Workshop Resource Hub

A mobile-first, static resource page for the SADEEM workshop **HOW TO STUDY USING AI**.

## Files
- `index.html` – page content and resource links
- `style.css` – responsive styling and SADEEM colors/fonts
- `script.js` – small progressive enhancement
- `assets/` – official logo files

## Publish (GitHub Pages – free)
1. Create a new public GitHub repository, e.g. `sadeem-workshop-resources`.
2. Upload the contents of this folder (keep `index.html`, `style.css`, `script.js`, and `assets/` at the repository root).
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**, select `main` and `/ (root)`, then Save.
5. Wait for GitHub Pages to publish. Your public URL will look like:
   `https://YOUR-USERNAME.github.io/sadeem-workshop-resources/`
6. Open that URL on a phone using mobile data or an incognito/private browser to test it.

## Check Google Drive permissions
The three PDF links are the share links supplied for this project. In Google Drive, open each PDF's **Share** settings and set **General access → Anyone with the link → Viewer** if you want every workshop participant to open it. Test each link in a private/incognito browser before the workshop.
